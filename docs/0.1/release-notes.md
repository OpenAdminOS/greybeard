# Greybeard 0.1.2

Prepared release notes. This version has not been published; downloads and signatures must be verified before publication.

## Changes

- Optional private shared memory for multiple computers, with headless server commands and connection settings under App preferences > Advanced.
- Shared MCP memory, automatic mentoring, exact human review, corrections, export, memory map, and advice activity.
- Protected and revocable device credentials, separate review authority, private HTTPS, device/shared pause controls, and bounded failures when offline.
- Existing local setup and memories remain the default. Connecting does not automatically upload local records; disconnect returns to the retained local store.

See the [operator guide](../0.1.2/shared-memory.md) and [verification gates](../0.1.2/implementation-status.md). Physical multi-machine host conversations and native remote workflows on each advertised client platform must be verified before shipping.

The previously published downloads and features are recorded in the [0.1.1 release notes](release-notes-0.1.1.md).
