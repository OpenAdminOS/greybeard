# Greybeard 0.1 build specification

**An IT mentor that learns how you work.**

The current implementation contract is [the 0.1 implementation plan](docs/0.1/implementation-plan.md), informed by [the independent review decisions](docs/0.1/review-decisions.md). [Implementation status](docs/0.1/implementation-status.md) separates demonstrated behavior from remaining release work.

The product is free, local, and useful without a tenant connection. It ships as one executable with graphical and terminal setup. MCP provides tools, skills provide domain guidance, and host integrations provide supported action events. Model proposals are candidates until the admin confirms the exact revision through local controls. Advice is bounded, scoped, and optional. Tenant reads use a customer-owned app-only credential with individually selected capabilities. Production writes are disabled in 0.1.

Executable delivery, native extraction, trusted metadata, and recovery are specified in [executable delivery](docs/0.1/executable-delivery.md). The actual MCP surface is documented in [MCP tools](docs/mcp-tools.md). Token savings are not assumed or promised.

The [original build spec](docs/history/original-build-spec.md) is retained for historical context. Its delegated authentication, write-gate release scope, automatic Git update, and client-parity claims do not govern 0.1.
